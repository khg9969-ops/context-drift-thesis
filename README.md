# 김호겸의 석사학위 연구 소개

**임베딩 모델을 활용한 맥락 이탈 탐지 알고리즘**

부산대학교 대학원 정보융합공학과 · 지도교수 김태운 · 2027년 2월 공학석사 예정

## 공개 홈페이지

[임베딩 모델을 활용한 맥락 이탈 탐지 알고리즘](https://khg9969-ops.github.io/context-drift-thesis/)

[GitHub 저장소](https://github.com/khg9969-ops/context-drift-thesis)

페이지는 연구 개요, 연구 동기, 연구 내용, 실험 설계, 결과 및 성능, 참고문헌, 관련 사이트·자료, 논문 정보의 **8페이지**입니다. HTML·CSS·JavaScript로 동작하며 설치하거나 빌드할 패키지가 없습니다.

## 내용 수정

- `research-data.js`: 논문 제목, 이름, 이메일, 지도교수, 요약, 참고문헌, 관련 사이트, 예비실험 집계.
- `site.js`: 각 페이지 본문 구성과 차트·필터·다운로드 기능.
- `site.css`: 공통 디자인과 모바일 화면.
- `final-results.json`: 최종 실험이 끝나면 공개할 결과. 현재 측정값은 비어 있습니다.

GitHub에서 해당 파일의 연필 버튼을 눌러 수정하고 변경사항을 저장하면 GitHub Pages에 반영됩니다. 학교 신청서에서 논문 제목을 변경했다면 제목과 요약, 게시판 정보를 함께 일치시킵니다.

## 최종 결과 추가

`final-results.json`의 `updated`를 측정·확정 날짜로 바꾸고 결과 배열을 채웁니다. 값은 실제 측정값만 입력합니다.

각 `comparisons` 행은 다음 정보를 포함합니다.

```json
{
  "budget": 650000,
  "model": "모델 이름",
  "model_id": "jina 또는 kure 또는 bge",
  "method": "방법 이름",
  "method_id": "full 또는 cosine_supervised",
  "goal": 0.05,
  "AP": null,
  "AUROC": null,
  "Precision": null,
  "Recall": null,
  "FPR": null,
  "tp": null,
  "fp": null,
  "tn": null,
  "fn": null
}
```

위 코드는 **필드 설명용**이며 실제 결과 배열에 그대로 넣지 않습니다. `null`은 미측정 값을 뜻합니다. 정밀도·재현율·FPR은 백분율 숫자 대신 **0~1 사이 비율**로 입력합니다. `tp + fp + tn + fn`은 해당 시험 응답 수와 같아야 합니다.

- `comparisons`: 모델·입력 예산·방법별 AP/AUROC와 5% 운영점.
- `operatingPoints`: 같은 모델·방법·예산의 목표 1%, 5%, 10%에 대한 실측 운영점. 모델·방법 ID, `goal`, `Precision`, `Recall`, `FPR`, TP·FP·TN·FN을 포함합니다.
- `methods`: 65만 입력의 5% 운영 기준에서 방법별 비교 결과.

현재 필터는 연구에서 사용한 모델 3종, 입력 예산 65만·100만·120만, 두 주 비교 방법에 맞춰져 있습니다. 다른 모델이나 예산을 추가할 경우 `site.js`의 필터 항목도 함께 수정합니다.

`research-data.js`의 `releases` 항목에는 최종논문·재현 코드·시연영상·테스트 데이터 안내의 공개 URL을 연결할 수 있습니다. 파일을 저장소에 넣을 경우 `url`에는 상대경로 대신 해당 파일의 완전한 `https://` 주소를 입력합니다.

## 연구 결과와 데이터 범위

현재 결과는 **예비실험 · 2026-09-16 재검토 자료**입니다. 최종 논문 성능과 구분합니다.

- 주 정답은 한국어 응답 **적절성 부적합**입니다. 순수 맥락 이탈·사실 오류 정답으로 확대하지 않습니다.
- AP는 정확도가 아닙니다. 보정자료의 목표 FPR과 시험자료의 실제 FPR을 구분합니다.
- 65만·100만·120만은 중복 제거한 임베딩 입력 문자열 예산입니다. 인코더 추가 학습량이나 시험 건수가 아닙니다.
- 이 저장소에는 **집계 지표와 직접 작성한 설명 예시**만 포함합니다. AI Hub 원자료, 개별 대화 원문, 승인받지 않은 제3자가 열람할 수 없는 데이터는 재배포하지 않습니다. 원자료는 관련 사이트 페이지의 공식 제공처에서 이용 조건에 따라 신청합니다.

## 지역 미리보기

Python이 설치되어 있다면 저장소 폴더에서 `python -m http.server 4173`을 실행하고 `http://localhost:4173/`을 엽니다. 주소의 하위 경로에서도 작동하도록 모든 내부 링크는 상대경로로 구성했습니다.

## GitHub Pages 설정

**Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

`.nojekyll`을 포함하여 정적 파일을 그대로 제공합니다. 배포가 끝나면 Pages의 공개 주소가 실제로 열리는지 확인한 뒤 학과 석사학위논문 게시판에 등록합니다.

학과 안내에 따라 졸업 후에도 연구실에서 최소 2년간 관리·운영합니다.
